# delta9043.github.io

Personal academic website / CV, hosted with GitHub Pages.

Live site: https://delta9043.github.io

## Structure

- `index.html` — the entire page (inline CSS + JS). Sections: About, Experience, Publications (with a Selected / All toggle), Honors & Awards, Academic Services.
- `assets/img/profile.jpg` — profile photo. `khu-emblem.png` (Education) and `EMIL.png` (Research Experience) are section logos.
- `assets/pdf/cv.pdf` — put your CV PDF here (referenced by the CV icon and About section).

## Notes

- Icons use Font Awesome + Academicons, fonts use Noto Sans KR — all loaded from CDNs, so an internet connection is needed to render them.
- To mark a publication as "Selected", add the `selected` class to its `.pub-item` div.

Open `index.html` in a browser to preview locally.
