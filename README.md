# delta9043.github.io

Personal academic website / CV, hosted with GitHub Pages.

Live site: https://delta9043.github.io

## Edit

- `index.html` — all content (bio, news, publications, education).
- `assets/css/style.css` — styling.
- `assets/images/` — profile photo and paper teasers. Replace the `.svg` placeholders with your own images (update the `src` paths in `index.html` if you change file names/extensions).

Open `index.html` in a browser to preview locally.
